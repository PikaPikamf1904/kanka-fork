# The Synthetic Chronicle: campaign knowledge from Chronicle

*Exported from Chronicle on 2026-11-24 by the DM. Private: contains DM-only secrets; do not share with players.*

**How to read the labels.** Every section and fact says where it came from and who knows it:
- **Established lore (official reference)** — official Dragonlance setting material recorded in Chronicle.
- **Campaign canon (confirmed at the table)** — happened in a played session.
- **DM-confirmed** — the DM has confirmed it as true. When it is also “DM only”, it is a DM-approved secret the players have not learned.
- **From session transcripts, not yet confirmed** — taken from session transcripts and not yet checked; treat as uncertain.
- **Planned, not yet played** — a plan for the future. It has not happened.
- **Unclassified** — Chronicle has no label for it. Do not assume it is canon, a plan or speculation.
- **Visibility:** “Known to players” (players can read it in Chronicle), “DM only (secret)” or “DM only (draft)”.
- Gazette stories are in-world newspaper reports; a “rumor” or “satire” report is not established fact.
- Connections are saved links between pages, written source → kind → target, with any custom description in quotes. Mentions in text are not connections.
